## 干净安装与首次使用

- [ ] 在无 Sakura 数据的新用户或干净 Mac 上解压候选包，将 Sakura.app 放入“应用程序”；按随包说明处理未签名提示，记录系统实际提示。不要关闭 Gatekeeper。
- [ ] 首次双击，确认菜单栏花朵与设置窗口出现、版本正确；默认动画是「Welcome · 彩虹手写」（动画库里同时有雷电将军与几何示例），自动运行默认未开启。
- [ ] 动画库中可手动选择「雷电将军 · 花园」并预览；切回几何示例。只在已确认使用权的情况下测试自己的导入内容。
- [ ] 按引导选应用、预览、保存；再次双击打开同一设置窗口，未保存草稿不会用于自动播放。退出后重新打开仍保留已保存选择。

## 真实应用与显示器

- [ ] 选择真实目标（记名称/版本和 Dock、Spotlight 或其他原有入口），完整退出目标后再启动；动画及时出现、无黑屏，窗口出现后跟随并淡出，焦点能交给目标且可输入。
- [ ] 目标启动前已运行时，启动 Sakura 不补播；分别测试 Esc、Command+.、点击跳过及切到其他应用，画面及时退出。
- [ ] 两个不同目标分别指定动画，依次及同时启动，记录播放选择与冲突处理；测试“窗口重新出现时也播放”、最小化/隐藏恢复不误播。
- [ ] 双屏下分别从两屏启动、移动/缩放目标到另一屏，检查负坐标与不同缩放；断开外屏再启动，画面保持可见且可跳过。
- [ ] 播放时与等待时分别睡眠/唤醒，确认没有残留遮罩，下一次真实冷启动仍正常。
- [ ] 开启系统“减少动态效果”，检查默认抑制与用户允许后的行为；其他应用全屏时默认不播，退出全屏后恢复。
- [ ] 测试静音、音量和淡出、循环接缝；测试坏包/缺失包和导入失败，现有动画不受损。不要改动唯一一份个人素材。
- [ ] 测试每天首次播放与临时暂停；设置与概览原因一致。“测试”按钮的结论与实际目标情况一致。

## 升级与卸载（使用可恢复备份）

- [ ] 在旧版准备非默认当前动画、每应用选包、收藏、方案、音量/频率、引导偏好；备份数据并记下值。退出旧版后替换应用，升级后逐项核对，特别是已选精选动画不会被强制切换成 Welcome 或几何示例。
- [ ] 在旧版移除精选动画，升级/重启后确认它未自动装回；CC0 示例仍可用。
- [ ] 若主动测试登录项，先记录原状态，开启后注销/登录：保持安静、不误触发目标；随后关闭，验证系统登录项已关闭。未测试则记“未执行”。
- [ ] 关闭 Sakura 自动运行并退出，删除应用，确认无 Sakura 进程；保留数据重装后仍保留设置。
- [ ] 仅在已备份且确认要清理的测试账户中按隐私说明清理数据及偏好，再装应恢复「Welcome · 彩虹手写」默认值；记录清理范围，勿删除日常账户的数据。
