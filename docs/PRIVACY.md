# 数据与隐私

本说明适用于当前开发者预览源码。设置、动画包和事件日志由本机处理；当前应用源码没有账号登录、遥测、云同步、在线资源目录或自动安装更新的模块；唯一的联网功能是下面的“检查更新”。此说明不是对未来版本或操作系统后台网络活动的永久保证。

## 应用识别

Sakura 枚举已安装应用供用户选择，再依据所选目标的进程身份和窗口状态决定何时播放。Mac 使用 bundle identifier；Windows 使用包身份或可执行文件路径。窗口位置、尺寸、可见状态和前台切换用于跟随与退出。它不需要 OpenAI API 密钥，不修改目标应用文件，不读取聊天数据库，也没有屏幕录制功能。

## 本地数据

| 平台 | 默认位置 |
| --- | --- |
| macOS | `~/Library/Application Support/GardenBoot/`，部分偏好在应用的 UserDefaults 中 |
| Windows | `%LOCALAPPDATA%/GardenBoot/` |

包括导入的动画包、个人参数、播放记录、轮换状态和是否收起使用引导的本地偏好。收起引导不会保存参数草稿。`events.log` 记录启动、选包、播放、跟随、退出及失败事件，约 512 KiB 后轮换；异常消息可能含本机路径，分享前请检查。封面缓存位于系统缓存目录。

`GardenBoot` 是保留的内部存储名称，界面产品名为 Sakura；保留它可避免用户配置因更名丢失。

## 检查更新（唯一的联网功能）

从 0.2.0-preview.5 起，Sakura 会检查 GitHub 上是否有新版本（规则见 [UPDATES.md](../launcher-spec/UPDATES.md)）：

- 只请求 `https://api.github.com/repos/shishyguo-cyber/sakura-launcher/releases`，读取公开的版本列表；`User-Agent` 为 `Sakura/<当前版本>`。
- 不发送账号、设备标识、设置、动画或使用数据。和任何网络请求一样，GitHub 能看到请求方的 IP 地址。
- “自动检查更新”默认打开，最多每 7 天联网一次；可在菜单栏/托盘菜单里取消勾选，之后不再自动联网。“检查更新…”只在你点击时联网。
- 发现新版本只提示并打开下载页，不会自动下载、替换或运行任何文件。查到的版本号和下载页地址保存在本机偏好中。

## 登录与删除

开机自动运行仅在用户主动开启时设置：Mac 使用系统登录项，Windows 使用当前用户的 Run 配置。不开启时不会因为构建或预览而自动启用。

移除动画包会将它送至废纸篓或回收站，个人方案可能继续保留对应参数。卸载与清理数据前先退出 Sakura、关闭其自动运行，再按[平台说明](../README.md)处理；保存的动画包请自行备份。

未来若增加在线推荐或扩展下载，应在对应版本明确说明请求目标、发送的数据与关闭方式，再更新本文件。
