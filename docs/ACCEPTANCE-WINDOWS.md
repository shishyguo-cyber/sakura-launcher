## 无 .NET 的干净环境

- [ ] 创建全新 Windows 11 x64 环境，记录系统版本；用 `where.exe dotnet`、已安装应用列表及 `C:\Program Files\dotnet\shared` 检查并记录确实未安装 .NET SDK / .NET 10 Desktop Runtime。若环境预装了运行时，换干净镜像，不能将此项勾为通过。
- [ ] 复制候选 ZIP 与校验值，用 `Get-FileHash <ZIP> -Algorithm SHA256` 核对，解压整个 Sakura 文件夹至普通用户可写固定目录；不要只复制 EXE，不安装 .NET。
- [ ] 双击 Sakura.exe，记录 SmartScreen 实际提示并按随包说明处理。设置窗口与托盘花朵出现，无要求安装 .NET 的弹窗；版本正确。自包含包应带有 coreclr.dll、hostfxr.dll、PresentationFramework.dll 等文件。
- [ ] 新安装默认是「Welcome · 彩虹手写」（动画库里同时有雷电将军与 CC0 几何示例）、自动运行未开启；预览时黑底彩虹线写出 welcome；在「播放」页填称呼后预览会写出该称呼；动画库可切换到其他动画再切回。退出、重新打开与再次双击的行为正常。
- [ ] 从应用列表选择该环境中真实目标，保存并做一次完整退出后的冷启动，确认媒体能解码、跟随窗口并淡出，目标可获得焦点与输入。记录目标/入口，不能以只出现设置窗口代替播放验收。
- [ ] 退出并删除程序文件夹，确认进程退出；按隐私说明仅清理测试环境数据。重新解压首次运行恢复 CC0 默认值。销毁沙盒后不保留测试数据。

## 日常 Windows 实际场景（先备份）

- [ ] 记录真实目标与版本，完整退出后从原有快捷方式/开始菜单启动；无黑屏、淡出及时、窗口跟随、焦点与输入正常。启动 Sakura 前已运行的目标不补播。
- [ ] 测试 Esc、点击跳过、切到另一应用与关闭目标；同时启动两个目标，核对每应用选包与冲突行为；后台应用的窗口重现可选开关正常，最小化恢复不误播。
- [ ] 双屏和混合 DPI 下分别从两屏启动、跨屏移动/缩放目标；测试负坐标、拔掉外屏后重试，无失踪遮罩或画面越界。
- [ ] 等待及播放中分别睡眠/恢复，确认遮罩消失，下一次冷启动可正常播放；重启 Explorer 后托盘图标和设置入口恢复。
- [ ] 其他应用全屏/演示时默认不播；系统减少动画相关设置按产品行为处理；检查静音、音量、声音淡出与循环接缝。
- [ ] 坏包、缺少当前动画、导入失败可恢复；旧动画不被损坏；暂停、每天首次播放、概览状态与“测试”结论符合实际。

## 升级、保留设置与卸载

- [ ] 旧版设置自选全局动画、每应用选包、收藏、方案、音量/频率、引导偏好；备份 `%LOCALAPPDATA%\GardenBoot` 并记录值。退出旧版，替换整个应用目录，升级后逐项核对，当前精选/个人动画不被切回 CC0。
