Sakura {version}（开发者预览版）· macOS 13 及以上

安装
1. 把 Sakura.app 拖到“应用程序”文件夹。
2. 第一次打开：这个预览版没有 Apple 开发者签名和公证，系统会提示“无法验证开发者”。
   请打开“系统设置 → 隐私与安全性”，在页面下方点“仍要打开”，再确认一次。
   （以后正常双击即可。）
3. Sakura 在菜单栏显示花朵图标。手动打开时会弹出设置；按“概览”的三步引导选择应用、选择动画、预览并保存。

说明
- 适用于 Apple 芯片 Mac；包内也含 Intel 版本，但尚未在 Intel Mac 上实测。
- 开机自动运行需要在菜单里主动开启。
- 内置两段动画：默认使用的同人动画「雷电将军 · 花园」（仅供个人非商业使用），以及原创几何示例；也可以“导入动画包”或“从视频创建”自己的动画。
- 卸载：先在菜单中关闭“开机自动运行”，再退出 Sakura 并删除 Sakura.app；个人设置在 ~/Library/Application Support/GardenBoot，可备份后按需保留或删除。
