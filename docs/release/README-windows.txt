Sakura {version}（开发者预览版）· Windows 11 64 位（当前验证平台）

需要先安装：.NET 10 桌面运行时（Windows Desktop Runtime 10，x64）。
没装时双击 Sakura.exe，Windows 会弹出提示并给出微软官方下载链接。

安装
1. 把整个 Sakura 文件夹解压到固定位置（例如 文档\Sakura），不要只拿出 Sakura.exe。
2. 双击 Sakura.exe。这个预览版没有代码签名，Windows 可能提示“Windows 已保护你的电脑”，
   点“更多信息 → 仍要运行”。
3. Sakura 在任务栏右下角托盘显示花朵图标。手动打开时会弹出设置；按“概览”的三步引导选择应用、选择动画、预览并保存。

说明
- 开机自动运行需要在托盘菜单里主动开启。
- 内置的是原创几何示例动画；可以“导入动画包”或“从视频创建”自己的动画。
- 卸载：先在托盘菜单关闭“开机自动运行”，再退出并删除 Sakura 文件夹；个人设置在 %LOCALAPPDATA%\GardenBoot，可备份后按需保留或删除。
