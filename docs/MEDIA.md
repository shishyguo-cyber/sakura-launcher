# 媒体与动画包

代码许可不等于素材许可。内置几何示例和问候背景分别采用 [几何示例 CC0 声明](../launcher-macos/demo-pack/NOTICE.md)和 [问候 CC0 声明](../launcher-macos/greeting-pack/NOTICE.md)；用户导入的图片、视频、音乐、模型和派生内容继续适用各自权利与许可。

动画包格式见[共享规格](../launcher-spec/PACK-FORMAT.md)。包作者应在 NOTICE.md 中标明作者、来源、许可入口和允许的使用方式；有多项来源时逐项列出。未经确认，不应将“可以二次创作”写成“允许公开原始素材或再分发”。

第三方角色、模型、参考图或音乐只有在确认适用许可或另有充分权利依据时才进入公开仓库或发布附件。放到 GitHub Release、标记同人或声明无隶属关系，不会自动增加发布者的权利。

本仓库不包含私人动画制作工作区、Remotion 项目或原始模型。未来若公开制作工具，应单独整理可移植依赖与许可证，不能用 Sakura 的 MIT 许可覆盖依赖或第三方素材。

问题报告中的截图请使用 CC0 示例，避免上传私人路径或未授权角色画面。

本仓库自有界面图形与界面截图按 MIT 随源码提供；截图中的几何示例仍遵循其 CC0 声明。截图许可不扩大到任何未来加入的第三方画面。
