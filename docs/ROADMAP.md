# 路线图

Sakura 希望成为可持续维护的桌面体验工具。当前首个场景是应用启动动画；后续能力由真实使用反馈决定。

## 当前已有

两端原生应用、动画包与参数方案、动画库和轮换、播放频率、多目标应用、按应用的播放状态说明、三步使用引导与共享一致性用例。

## 下一阶段

完善干净环境构建、自动检查、安装与卸载说明、真实冷启动、多屏体验与可分发安装包。改善错误提示、无障碍支持和文档。

## 后续评估

经过验证的 Codex 相关资源推荐、工作流与原创扩展、更丰富的原创动画制作工具和实时视觉能力。这些属于候选方向，尚未实现；不会把所有 GitHub 仓库当成可一键安装的插件。

在线能力需要独立设计数据来源、许可、兼容性、验证日期和隐私边界。本地动画功能应在在线模块不可用时继续工作。

这里不承诺日期；具体版本以更新记录与 Release notes 为准。
