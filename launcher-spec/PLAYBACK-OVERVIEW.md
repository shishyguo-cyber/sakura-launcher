# 播放状态与使用引导

概览面向普通用户说明当前自动播放条件。按已保存、本机支持的目标应用逐个查看；草稿不作为实际监听配置。渲染预览未连接运行态时明确标为“界面预览”。

解析优先级：实际预览/播放 → 准备 → 无目标/禁用 → 暂停 → 系统减少动态效果 → 登录宽限/隐藏启动 → 临时暂停 → 有效包的最近失败 → 今日已播 → 无可用包 → 已有进程基线 → 等待下次启动。频率仍由现有 ScheduleDecision 按目标和本地日期计算；状态层不另写日期规则。

字段与优先级用例见 conformance/overview.json。状态不通过解析日志获得，也不表示知道目标软件的真实加载进度。窗口或进程存在只说明已运行，不能视为完成加载。

概览状态依据已保存设置，每秒刷新并在窗口关闭后停止。失败只在同一目标和动画包仍有效时提示，重试或修改包后可以恢复；当前预览不受自动播放频率和暂停限制。

引导可关闭、重新查看。三步操作分别导航到应用、动画并预览当前调整；不自动启动真实目标、不保存参数、不启用自启。关闭引导仅保存平台本地可选偏好，experience 和包格式不升级。首次手动启动或再次双击打开设置，登录自启及非设置类测试命令保持安静。

明确的最近媒体失败优先于“今日已播”提示：一次失败可能已经产生今日记录，不应让次数提示掩盖可修复的问题。播放引擎的实际调度顺序不变；完成一次成功播放后清除同包失败提示。
