# 界面设计规范 v2「花园清新」（P-008）

用户 2026-11-15 认为 v1（P-007）“太丑”，从三个方向中选定 **A 花园清新**。v1 的问题：整页长表单、说明文字过多、没有视觉中心、控件和配色都像默认样式。v2 保留全部行为，只重做呈现。产品名为 **Sakura**（用户 2026-11-15 确定）；界面、菜单、窗口标题、程序文件（Sakura.app / Sakura.exe）统一使用。内部代码名与数据目录仍为 GardenBoot，以免丢失已有设置。

## 2. 字体与尺寸

- 字体：macOS 系统字体；Windows `Segoe UI Variable Text, Microsoft YaHei UI`。字号：品牌名 13 半粗；预览区动画名 18 半粗；数值卡片数值 16 半粗；正文 13；标签/说明 12。数值用等宽数字。
- 间距 4/8/12/16/24；内容区内边距 24；圆角：预览区 14、卡片与分组列表 12、导航项与按钮 8、预览胶囊按钮 16、封面 8。
- 窗口默认 960 × 640，最小 820 × 560；左侧导航宽 180。

## 3. 窗口结构

```
┌ 导航 180 ──────┬ 内容区（每次只显示一页）────────────────────────┐
│ ✿ Sakura    │ ┌ 预览区（hero，薄荷底，圆角 14）────────────┐ │
│ ▸ 动画（选中）  │ │ [封面 16:9]  夜色 · 花园          [▶ 预览] │ │
│   播放          │ │              当前动画 · 14 秒              │ │
│   声音与过渡    │ └────────────────────────────────────────────┘ │
│   显示          │   页面内容（数值卡片 / 分组列表 / 动画网格）    │
│   我的方案      │                                                 │
│                 │                                                 │
│ ● 有未保存的修改│ ─────────────────────────────────────────────── │
│ [  保存设置  ]  │                                                 │
└────────────────┴─────────────────────────────────────────────────┘
```

- **导航**（`sidebar` 底）：顶部五瓣花图标 + “Sakura”；七个页面项，各带一个线性图标——概览（房屋）、动画（影片）、应用（应用列表）、播放（播放三角）、声音与过渡（扬声器）、显示（窗口/画面比例）、我的方案（书签）。默认打开概览。选中项 `surface` 底、`accent` 文字、半粗；悬停 `hover`。导航底部固定：保存状态一行（`当前设置` / `● 有未保存的修改`（accent）/ `✓ 设置已保存`（success））＋ 全宽主按钮“保存设置”（`accentFill`，⌘S / Ctrl+S）。
- **预览区（每页顶部）**：`hero` 底、圆角 14、内边距 16，高 136。左侧当前正在调节的动画封面（16:9，高 104，圆角 8；无封面用首帧，取不到用浅色占位＋五瓣花）；右侧动画名（`heroText` 18 半粗）、副标题（`heroSecondary` 12，如“当前动画 · 14 秒”“轮换中”）；右下“▶ 预览”胶囊按钮（`surface` 底、`accent` 文字，⌘P / Ctrl+P，预览草稿）。动画页之外的页面同样显示，作为“正在调节谁”的上下文。
- **页面内容**：
  - 概览：薄荷状态卡按已保存的目标应用显示原因与操作入口；可关闭和重新查看的三步引导位于下方。未保存时明确显示草稿提示。此页不重复展示动画预览区，内容在小窗口可滚动，保存按钮保持可见。行为见 `PLAYBACK-OVERVIEW.md`。
  - 动画：一行“自动播放时 [固定播放当前动画 ▾]”；下方动画网格，每行 3 个封面卡片（16:9 封面、名称、右上收藏星、“当前”标签；选中描边 `accent` 1.5、底 `accentSoft`）；卡片下方小号文字按钮“设为当前 · 移除…”（移除为 `danger`，示例动画禁用）；网格末尾虚线“＋ 导入动画包”卡片。点卡片切换正在调节的动画（预览区随之变化），其他动画的未保存修改仍保留。无法使用的包在网格下方用 `danger` 小字列出。
  - 播放：分组列表——“播放频率 [每次启动 | 每天首次]”（分段控件）；选每天首次时出现“新的一天从 [4:00 ▾] 开始”与今日状态（“今天已于 09:12 播放”）＋文字按钮“下次启动照常播放”。一行说明：“临时暂停在托盘/菜单栏菜单里。”
  - 声音与过渡：先一排三个数值卡片（淡出 / 最长等待 / 窗口就绪时），显示当前生效值，点卡片滚到对应行；下面分组列表：总音量（滑块＋百分比＋“静音”开关＋文字按钮“恢复音量”）、淡出时长、淡出起点、最长等待、窗口就绪时。每个可覆盖参数行：标题＋右侧“自定义”开关；打开后行内展开滑块/输入框，关闭时只在右侧以 `textSecondary` 显示默认值（如“默认 0.4 秒”）。
  - 显示：分组列表——开场尺寸（同上自定义行）、贴到窗口时 [自动适配（推荐） ▾]。
  - 我的方案：已存方案列表（每行：名称、“应用”文字按钮、“删除” `danger` 文字按钮）；末行输入框“方案名称”＋“存为方案”；下方次按钮“恢复本包默认参数”＋一行说明“不会删除已存方案。”
- **说明文字**：每页最多一行常驻说明；其余解释放进悬停提示（tooltip）。

## 4. 控件

- 分组列表：`surface` 底、`border` 描边、圆角 12；行高 ≥ 44，左右内边距 14，行间 `divider` 细线。
- 数值卡片：`surface` 底、`border` 描边、圆角 12，内边距 12；上 `textSecondary` 12 标签，下 16 半粗数值。
- 开关：轨道 32 × 18，关 `accentSoft`（深色用 `border`），开 `accentFill`，圆钮 `onAccent`。
- 滑块：轨道 4，已选 `accentFill`、未选 `accentSoft`；圆钮 16，`surface` 填充 + 2px `accentFill` 描边。
- 分段控件：`accentSoft` 底、圆角 8；选中段 `surface` 底、`accent` 文字。
- 下拉框/输入框：`surface` 底、`border` 描边、圆角 8、高 32；获得焦点描边 `accent`。
- 按钮：主按钮仅“保存设置”；胶囊按钮仅“▶ 预览”；其余为文字按钮（`accent`）或次按钮（`surface`+`border`）。
- 焦点环：2px `accent`，仅键盘焦点显示。

## 6. 统一用词

| 位置 | 用词 |
|---|---|
| 轮换选项 | 固定播放当前动画 / 全部动画随机 / 收藏动画随机 |
| 频率 | 每次启动 / 每天首次 |
| 适配选项 | 使用动画默认设置 / 自动适配（推荐） / 铺满（可能裁边） / 完整显示（模糊补边） |
| 音量恢复 | 恢复音量 |
| 参数默认值 | 默认 0.4 秒 / 默认 72% |
| 保存状态 | 当前设置 / 有未保存的修改 / 设置已保存 |

面向用户统一说“动画”，只有导入文件夹时说“动画包”。按钮不带句号；说明是完整句子带句号；数字与单位之间留空格。

## 7. 评审方式

- Windows：UiChecks 检查页面导航、状态与草稿隔离、引导动作、空库恢复，并渲染概览默认尺寸与 820 × 560 小窗口；外观跟随测试桌面系统。
- macOS：`--render-settings <png> [--appearance light|dark] [--page overview|animation|targets|playback|sound|display|presets] [--size 820x560]`。七页浅色，概览/动画/应用页深色，另检查概览最小窗口。
- 统筹并排对比两端，交用户审看。
