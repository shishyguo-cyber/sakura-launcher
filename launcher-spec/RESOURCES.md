# 资源占用预算（P-012）

Sakura 大部分时间都在后台等待，所以“等待时几乎不占资源”是质量要求的一部分。

## 预算（空闲等待、一个目标应用、没有播放）

| 指标 | 上限 |
|---|---|
| 平均 CPU | 单核 0.5% 以内（每分钟 ≤ 0.3 秒 CPU 时间） |
| 常驻内存 | 100 MB 以内（含预热好的第一段视频） |

改动监听、预热或轮询逻辑后要重新测量；超出预算视为缺陷。

## 测量方法

- macOS：用独立测试目录启动构建产物，目标设为一个不存在的 bundleId，等 15 秒稳定后取 60 秒内 `ps -o time` 的增量和 `rss`。
- Windows：`launcher-windows/scripts/measure-idle.ps1 -Exe <Sakura.exe> -Work <工作目录>`（同样的独立目录与不存在的目标，报告每分钟 CPU 秒数、工作集、私有内存）。
