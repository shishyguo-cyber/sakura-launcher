# 视频适配目标窗口（P-004）

问题：动画贴到 ChatGPT/Codex 窗口上时，窗口比例因人而异；过去两端都按“铺满裁边”显示，窗口偏窄或偏方时画面两侧被裁掉。用户 2026-11-14 选定默认“自动适配”。

## 模式

| 值 | 名称 | 行为 |
|---|---|---|
| `auto`（默认） | 自动适配 | 铺满时被裁掉的比例 ≤ 12% 用 `fill`，否则用 `fit` |
| `fill` | 铺满 | 等比放大到盖满整个画框，超出部分裁掉（旧行为） |
| `fit` | 完整显示 | 等比缩放到整段视频都在画框内；空出的边用同一视频的模糊放大画面（等同 `fill` 的位置）铺满，不露黑边 |

裁掉比例 `crop = 1 − min(a, v) / max(a, v)`，`a` 为画框宽高比，`v` 为视频宽高比。`auto` 在 `crop ≤ 0.12` 时取 `fill`（16:10 窗口配 16:9 视频约裁 10%，仍铺满；3:2 约 15.6%，改为完整显示）。画框或视频尺寸无效（≤ 0 或非有限）时取 `fill`，内容矩形等于画框。

## 内容矩形

画框局部坐标（原点在左上，单位与画框相同），视频宽高比 `v`，画框 `W × H`：

- `fill`：`s = max(W / v, H)`；`fit`：`s = min(W / v, H)`。
- 内容宽 `v × s`、高 `s`，在画框内居中：`x = (W − 宽) / 2`，`y = (H − 高) / 2`。不取整，比较容差 1e-6。
- `fit` 时背景层按 `fill` 的内容矩形绘制并模糊（两端各自选择合适的模糊半径，建议画框短边的 4% 左右，叠 15–25% 黑色以区分主画面）。

## 生效范围与时机

- 每段视频的宽高比取自该段的实际画面尺寸。开场画框本就按视频比例计算，通常为 `fill` 且不裁。
- 画框大小变化（停靠到目标窗口、跟随窗口移动/缩放）时重新判断；`auto` 可以在播放中从 `fill` 切到 `fit`，切换无需动画。
- 跳过、淡出、交还焦点和点击跳过的范围不变（仍是整个画框）。

## 配置

- 启动包 manifest 可选 `videoFit`：`auto`、`fill` 或 `fit`，省略为 `auto`。不认识的值使包无效。
- 个人设置每包覆盖 `overrides.videoFit`（同样三个值或 null 继承），仍为 experience schemaVersion 2；解析顺序：个人覆盖 → 包默认 → `auto`。命名方案一并保存此项。
- 设置窗口“显示”分区：`自动适配（推荐）`、`铺满（可能裁边）`、`完整显示（模糊补边）`，另有“使用动画默认设置”。

共享用例：`conformance/geometry.json` 的 `videoFit`，`manifest.json` 与 `experience.json` 的新增用例。
