# 从视频创建动画（P-013）

用户 2026-11-15 同意：降低“做一个动画包”的门槛——不用手写 manifest，选一个视频就能变成动画。

## 流程

1. “动画”页在“导入动画包…”旁边增加文字按钮 **从视频创建…**。
2. 选择一个本机视频文件（mp4、m4v、mov）。
3. 小窗口：**名称**（默认取文件名，规则见下）+ 勾选 **“这个视频是我自己制作的，或我有权使用它”**（不勾选不能创建）+ “创建”/“取消”。
4. 创建：在临时目录生成单视频包（下表），然后走与“导入动画包”完全相同的导入检查（能解码、有画面、时长有效）；成功后设为当前动画，提示“已创建「名称」。可在‘声音与过渡’里调整淡出起点。”失败时提示原因，动画库不变。

| 文件 | 内容 |
|---|---|
| `manifest.json` | `{ "schemaVersion": 1, "id": <id>, "name": <名称>, "segments": { "video": "video.<扩展名>" } }`，其余参数用默认值（视频结尾前淡出） |
| `video.<扩展名>` | 选中视频的副本；扩展名转小写 |
| `NOTICE.md` | 见下 |

## 规则（`VideoPackRules`，两端一致，共享用例 `conformance/video-pack.json`）

- `defaultName(fileName)`：去掉最后一个扩展名；把 `_`、`-`、连续空白换成一个空格；去首尾空白；超过 40 个字形截到 40；结果为空时用“我的动画”。
- `extension(fileName)`：最后一个扩展名转小写，属于 mp4/m4v/mov 时返回，否则为 null（界面提示“请选择 mp4、m4v 或 mov 视频”）。
- `validName(name)`：去首尾空白后 1–40 个字形、不含控制字符。
- `makeId(random8)`：`video-` + 8 位小写十六进制（调用方提供随机数）；与已有包重复时重新生成。
- `notice(name, sourceFileName, date)`：

```
# <名称>

由 Sakura 从本地视频「<原文件名>」创建（<YYYY-MM-DD>）。
创建者确认这个视频是自己制作的，或有权使用它。
这个动画包只供个人使用；分享或发布前请自行确认素材权利。
```

原文件名只保留文件名部分，不写完整路径（避免把用户名、目录结构写进可分享的包）。
