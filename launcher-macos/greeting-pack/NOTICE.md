# Welcome · 彩虹手写 / Rainbow Welcome

macOS 版用彩虹霓虹线把「welcome + 你在设置里填的称呼」一笔一笔写出来，称呼改了动画就跟着变。笔画由系统自带的 Bradley Hand 字体现场提取，不随包分发字体文件。

`cover.png` 是动画库封面，由 Sakura 的离屏录制命令生成。`intro.mp4` / `outro.mp4` 是兼容用的无声背景视频，由同目录的 `generate.py` 生成，不含文字。视觉素材均由 Sakura 自制。

视频与封面以 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) 公开。生成脚本适用 Sakura 的 MIT 许可。
